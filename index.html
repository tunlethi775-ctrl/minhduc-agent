Agent
Studio

A simple workspace to create, organize, and preview AI agent configurations.

A space to shape your AI assistants

Agent Studio helps you define an agent role, save its instructions, record intended tools and knowledge sources, and review the configuration in one dashboard.

01 | Create

Name an agent, describe its goal, and add instructions that explain how it should help.

02 | Organize

Search, filter by status, edit, activate, or pause your agents.

03 | Preview

Send a message to see a sample response based on the current configuration.

Who is it for?

For anyone who wants to sketch a specialized AI assistant, experiment with role instructions, and keep agent configurations together. This is a static web app; its data is stored in the current browser.

Note: This page introduces the product and explains how to share it. To let others use the interactive website, publish the website source files with GitHub Pages. A guide page does not contain the web app functionality.
Using the app

Create an agent in a few steps

The dashboard shows sample agents, statuses, and recent updates. Create your own agent or edit an existing configuration.

1

Create

Select Create agent. Enter a name and goal, then add instructions, tools, or knowledge sources if needed.

2

Save

Choose Active, Draft, or Paused, then save the configuration.

3

Refine

Open an agent to review its details, edit its settings, activate it, or pause it.

4

Try chat

Send a question in the chat panel. The demo shows a sample response based on the agent configuration.

What works in this version?

Configuration management

Create, edit, delete, search, and filter agents. Changes are saved in localStorage in the current browser.

Clear status feedback

Shows agent status, success or error messages, and a preparing-response state in chat.

Responsive layout

The dashboard, detail view, and forms adapt to desktop and phone screens.

Known limitations

Chat does not call a real AI model. Responses are simulated. Tools and knowledge are configuration notes only; they do not execute or retrieve documents. Real AI requires a secure backend/API and a server-side API key. Never put a secret key in public JavaScript.
Share the website

Publish Agent Studio with GitHub Pages

To share the interactive website, upload its source files to a GitHub repository and enable GitHub Pages. A deployment workflow is included in the source package.

Files in the repository root: index.html | styles.css | app.js | favicon.svg | site.webmanifest | .nojekyll | README.md
Workflow: .github/workflows/pages.yml
01

Create a repository

On GitHub, create a new repository. Choose Public if you want anyone to access the website. Use a memorable name, such as minh-duc-agent-studio.

02

Upload the source

Extract the website package and upload the listed files to the repository. Keep the .github/workflows folder.

03

Enable Pages

Open Settings -> Pages. Under Build and deployment -> Source, select GitHub Actions.

04

Wait for deployment

Open the Actions tab and wait for the “Publish static site” workflow to finish. Return to Settings -> Pages and select Visit site to get the link.

05

Update later

Each push to the main branch triggers another website deployment.

Before publishing: GitHub Pages makes website content available on the Internet. A public repository also exposes its source code. Do not upload API keys, personal data, or private documents. GitHub Free supports Pages for public repositories.

Official reference: GitHub Docs - Configuring a publishing source for GitHub Pages.
